## Output Validation Summary

- **`sudo -l`**: Look for `NOPASSWD`, `(ALL)`, `(root)`, specific binaries, **wildcards**, and `env_keep+=LD_PRELOAD/LD_LIBRARY_PATH/BASH_ENV/PYTHONPATH`.
- **`find / -perm -4000`**: Cross-reference every SUID binary against GTFOBins. Custom binaries are high-value.
- **`getcap -r /`**: Look for `cap_setuid`, `cap_setgid`, `cap_dac_read_search`, `cap_sys_admin`, `cap_sys_ptrace`.
- **`test -w /etc/passwd` / `test -w /etc/shadow`**: If writable, instant root via new UID 0 account or hash replacement.
- **`cat /etc/crontab`**: Look for root cron jobs running **writable scripts** or binaries by **relative name** with a writable PATH.
- **`ls -la /etc/cron.*`**: Check script permissions — writable by current user = root.
- **`find / -writable -name "*.timer"` / `*.socket`**: Writable systemd timer/socket units = root via associated service or socket activation.
- **`id`**: Look for exotic groups: `disk`, `adm`, `docker`, `lxd`, `video`, `sudo`.
- **`uname -r`**: Cross-reference kernel version against DirtyCow, DirtyPipe, PwnKit, OverlayFS.
- **`cat /proc/sys/kernel/modprobe`**: If you have an arbitrary kernel write primitive, this path is a root execution target.
- **`apt list --installed | grep needrestart`**: Version < 3.8 on Ubuntu/Debian → PYTHONPATH injection CVE.
- **`cat /etc/exports`**: Look for `no_root_squash` — instant root via SUID on NFS share.
- **`busctl list`**: D-Bus services owned by root; check `/etc/dbus-1/system.d/` for weak policies.

## Privilege Escalation Checklist

Run these questions on every Linux target, in order:

1. **Who am I, and what can I already do?** → `id` (exotic groups), `sudo -l`, `uname -a`
2. **Are system files writable?** → `test -w /etc/passwd`, `test -w /etc/shadow`
3. **What SUID/SGID/capabilities exist?** → `find / -perm -4000`, `find / -perm -2000`, `getcap -r /`
4. **What runs as root on a schedule?** → `cat /etc/crontab`, `ls -la /etc/cron.*`, `pspy64`, `systemctl list-timers --all`, `find / -writable -name "*.timer"`
5. **What credentials can I find?** → config files, history, SSH keys, logs, `/etc/shadow` (if readable)
6. **Is the kernel or a service unpatched?** → `uname -r`, `linux-exploit-suggester.sh`, `pkexec --version`, `needrestart` version
7. **Am I in a container or can I escape one?** → `id | grep docker/lxd`, `find / -name docker.sock`
8. **Did I miss anything?** → LinPEAS as a final sanity check — confirm, don't replace manual enumeration
