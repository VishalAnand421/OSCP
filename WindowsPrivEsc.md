# OSCP Windows Privilege Escalation Master Cheatsheet

> Master reference table for OSCP exam preparation. Run `whoami /priv` and `winPEAS` first, then cross-reference this table.
>
> **Exam workflow**: Enumerate → Validate output → Match to technique → Exploit → Verify.

## Output Validation Summary

- **`icacls`**: Focus on whether the permission flag is **(F)/(M)/(W)** and whether the subject is **the current user or a group they belong to** (such as `Users`).
- **`accesschk`**: Focus on directly checking whether the output contains **`SERVICE_CHANGE_CONFIG`/`SERVICE_ALL_ACCESS`** (service configuration), or **`RW`** followed by the current user/`Users` (file write).
- **`whoami /priv`**: Focus on whether the privilege name appears and its state is **Enabled**.
- **`wmic service get`**: Focus on `PathName` (binary path — check for spaces and writability), `StartMode` (Auto = reboot-triggerable), and missing quotes in `PathName`.
- **`sc qc`**: Focus on `BINARY_PATH_NAME` (unquoted path check) and `START_TYPE` (AUTO_START = reboot-triggerable).
- **Registry query**: Focus on whether the value is **`0x1`**.
- **`cmdkey /list`**: Look for saved credential entries (Target, User) that can be reused with `runas /savecred`.
- **`schtasks /query`**: Look for tasks running as SYSTEM whose target script/binary is writable.
- **`Get-LocalGroupMember Administrators`**: Identify high-value accounts to target for credential reuse.
- **`netstat -ano`**: Identify internal services (e.g., port 8080) that may be exploitable or reveal additional attack surface.

## Privilege Escalation Checklist

Run these five questions on every Windows target, in order:

1. **Who am I, and what can I already do?** → `whoami /priv`, `whoami /groups`, `Get-LocalGroupMember Administrators`
2. **What's installed, and does it leak anything?** → sensitive files (`*.kdbx`, `passwords.txt`, `my.ini`), configs (`web.config`), PowerShell logs (`ConsoleHost_history.txt`, Event ID 4104), PuTTY registry
3. **What runs with higher privileges than me, and can I touch it?** → services (`wmic service get`, `sc qc`, `icacls`, `accesschk`), scheduled tasks (`schtasks`), DLL search paths (Procmon)
4. **Is the box simply unpatched?** → `systeminfo`, `win32_quickfixengineering`, WES/wesng, SeImpersonatePrivilege abuse (PrintSpoofer/GodPotato)
5. **Did I miss anything?** → WinPEAS as a final sanity check — confirm, don't replace manual enumeration
